## 2. Two-Parameter Cusp Transversality Proof

To prove that the fold hysteresis represents a structurally stable, generic codimension-2 cusp catastrophe rather than an artifact of coordinate selection, the two-parameter unfolding is formalized under geostrophic shear $S_g$ and deep soil thermal flux $Q_G$.

$$F(e^*; S_g^*, Q_G^*) = 0, \quad \frac{\partial F}{\partial e}\Bigg\vert{}_* = 0, \quad \frac{\partial^2 F}{\partial e^2}\Bigg\vert{}_* = 0$$

with non-degeneracy condition:

$$\frac{\partial^3 F}{\partial e^3}\Bigg\vert{}_* \neq 0$$

### Transversality Determinant

The parameter transversality condition requires that the mapping from parameter space $(S_g, Q_G)$ to the unfolding space is non-singular. The transversality matrix $M_T$ is defined as:

$$M_T = \begin{bmatrix}  \dfrac{\partial F}{\partial S_g} & \dfrac{\partial F}{\partial Q_G} \\ \dfrac{\partial^2 F}{\partial e \partial S_g} & \dfrac{\partial^2 F}{\partial e \partial Q_G}  \end{bmatrix}_{\left(e^*, S_g^*, Q_G^*\right)}$$

The transversality proof is established by demonstrating:

$$\det(M_T) = \left( \frac{\partial F}{\partial S_g} \frac{\partial^2 F}{\partial e \partial Q_G} - \frac{\partial F}{\partial Q_G} \frac{\partial^2 F}{\partial e \partial S_g} \right)_{\left(e^*, S_g^*, Q_G^*\right)} \neq 0$$

When $\det(M_T) \neq 0$, the implicit function theorem guarantees that variations in geostrophic wind forcing $S_g$ and surface soil heat flux $Q_G$ smoothly slice through the cusp point, generating the characteristic hysteresis wedge in state space.

import numpy as np
from scipy.interpolate import BSpline

def build_intrinsic_bspline_library(t_vec, X_data, Psi_vec, num_splines=50, poly_order=3):
    """
    Constructs the weak formulation feature library matrix using cubic B-splines
    over the intrinsic time domain tau.

    Parameters:
    -----------
    t_vec : ndarray, shape (N,)
        Physical time vector (seconds).
    X_data : ndarray, shape (N, d)
        State space trajectories [e, q_theta, tau_m, S, Theta_z].
    Psi_vec : ndarray, shape (N,)
        Composite scale-separation confidence index Psi(t) in (0, 1].
    num_splines : int
        Number of test functions across the domain.
    poly_order : int
        Spline degree (3 for cubic B-splines).

    Returns:
    --------
    G_matrix : ndarray, shape (num_splines, num_features)
        Weak feature matrix (Theta_weak).
    b_vector : ndarray, shape (num_splines, d)
        Weak derivative target vector (dH/dtau_weak).
    """
    # 1. Compute Intrinsic Time Transformation tau(t) via cumulative trapezoidal integration
    d_tau = 1.0 / np.maximum(Psi_vec, 1e-4)
    tau_vec = np.zeros_like(t_vec)
    tau_vec[1:] = np.cumsum(0.5 * (d_tau[:-1] + d_tau[1:]) * np.diff(t_vec))

    # 2. Define uniform knot vector in intrinsic time domain tau
    tau_min, tau_max = tau_vec[0], tau_vec[-1]
    knots = np.linspace(tau_min, tau_max, num_splines - poly_order + 1)
    # Pad knots at boundaries for full spline construction
    knots = np.pad(knots, (poly_order, poly_order), mode='edge')

    # 3. Build candidate features in state space Theta(X)
    # Example library: polynomial terms up to degree 3
    e, q, tm, S, Tz = X_data.T
    Theta = np.column_stack([
        np.ones_like(e), e, q, tm, S, Tz,
        e**2, e*S, q*Tz, e**3, e**(1.5)
    ])
    num_features = Theta.shape[1]

    G_matrix = np.zeros((num_splines, num_features))
    b_vector = np.zeros((num_splines, X_data.shape[1]))

    # 4. Perform weak integration for each B-spline test function
    for j in range(num_splines):
        # Coefficients vector for j-th basis function
        c = np.zeros(num_splines)
        c[j] = 1.0
        spline_phi = BSpline(knots, c, poly_order)
        spline_dphi = spline_phi.derivative(1)

        # Evaluate basis and derivative on intrinsic grid
        phi_vals = spline_phi(tau_vec)
        dphi_vals = spline_dphi(tau_vec)

        # Weak Integration by Parts over intrinsic domain tau:
        # Int( dX/dtau * phi, dtau ) = - Int( X * dphi/dtau, dtau )
        for d_idx in range(X_data.shape[1]):
            b_vector[j, d_idx] = -np.trapz(X_data[:, d_idx] * dphi_vals, x=tau_vec)

        # Feature library integration against Psi(t) scaled features
        for f_idx in range(num_features):
            G_matrix[j, f_idx] = np.trapz(Psi_vec * Theta[:, f_idx] * phi_vals, x=tau_vec)

    return G_matrix, b_vector

using LinearAlgebra

"""
    eval_bspline_matrices(tau_vec::Vector{T}, knots::Vector{T}, p::Int) where {T<:Real}

Computes the (N × M) basis evaluation matrix `Phi` and derivative matrix `DPhi`
over the intrinsic time grid `tau_vec` using an iterative Cox-de Boor algorithm.
Vectorized over N and degree p to eliminate recursion bottlenecks.
"""
function eval_bspline_matrices(tau_vec::Vector{T}, knots::Vector{T}, p::Int) where {T<:Real}
    N = length(tau_vec)
    num_knots = length(knots)
    M_p1 = num_knots - p - 1 # Number of basis functions of degree p
    M_p0 = num_knots - p     # Number of basis functions of degree p-1

    # 1. Degree 0 basis matrix
    Phi_prev = zeros(T, N, M_p0)
    @inbounds for i in 1:N
        tau = tau_vec[i]
        for j in 1:M_p0
            if tau == knots[end] && j == M_p0 - 1
                Phi_prev[i, j] = one(T)
            elseif knots[j] <= tau < knots[j + 1]
                Phi_prev[i, j] = one(T)
            end
        end
    end

    # 2. Iterate up to degree p-1 and degree p
    Phi_curr = zeros(T, N, M_p0)
    for deg in 1:p
        M_deg = num_knots - deg - 1
        Phi_curr = zeros(T, N, M_deg)
        @inbounds for j in 1:M_deg
            denom1 = knots[j + deg] - knots[j]
            denom2 = knots[j + deg + 1] - knots[j + 1]

            inv1 = denom1 > 0 ? one(T) / denom1 : zero(T)
            inv2 = denom2 > 0 ? one(T) / denom2 : zero(T)

            for i in 1:N
                tau = tau_vec[i]
                t1 = inv1 > 0 ? (tau - knots[j]) * inv1 * Phi_prev[i, j] : zero(T)
                t2 = inv2 > 0 ? (knots[j + deg + 1] - tau) * inv2 * Phi_prev[i, j + 1] : zero(T)
                Phi_curr[i, j] = t1 + t2
            end
        end
        if deg < p
            Phi_prev = Phi_curr
        end
    end

    # Basis matrix at degree p
    Phi = Phi_curr

    # 3. Exact derivative matrix DPhi constructed from degree p-1 basis Phi_prev
    DPhi = zeros(T, N, M_p1)
    @inbounds for j in 1:M_p1
        denom1 = knots[j + p] - knots[j]
        denom2 = knots[j + p + 1] - knots[j + 1]

        inv1 = denom1 > 0 ? p / denom1 : zero(T)
        inv2 = denom2 > 0 ? p / denom2 : zero(T)

        for i in 1:N
            term1 = inv1 > 0 ? inv1 * Phi_prev[i, j] : zero(T)
            term2 = inv2 > 0 ? inv2 * Phi_prev[i, j + 1] : zero(T)
            DPhi[i, j] = term1 - term2
        end
    end

    return Phi, DPhi
end

    build_intrinsic_bspline_library(t_vec, X_data, Psi_vec;
                                     num_splines=50, poly_order=3,
                                     psi_floor=1e-4, check_partition=true)

Production-grade intrinsic-time WSINDy feature library builder.

# Key Features:
- **Exact Boundary Vanishing**: Trims endpoint basis functions so φ = φ_τ = 0 at domain limits.
- **Open Knot Vector**: Uses (p + 1) repeated knots at both boundaries.
- **BLAS Acceleration**: Replaces element-wise numerical integration with BLAS matrix products.
- **Non-Recursive de Boor**: Evaluates B-splines iteratively in O(p²) operations.
"""
function build_intrinsic_bspline_library(
    t_vec::Vector{Float64},
    X_data::Matrix{Float64},
    Psi_vec::Vector{Float64};
    num_splines::Int = 50,
    poly_order::Int = 3,
    psi_floor::Float64 = 1e-4,
    check_partition::Bool = true
)
    N, d = size(X_data)
    p = poly_order

    # 1. Desingularized Intrinsic Time Transformation: τ(t) = ∫ [1 / Ψ(s)] ds
    d_tau = 1.0 ./ max.(Psi_vec, psi_floor)
    tau_vec = zeros(N)
    @inbounds for i in 2:N
        tau_vec[i] = tau_vec[i - 1] + 0.5 * (d_tau[i - 1] + d_tau[i]) * (t_vec[i] - t_vec[i - 1])
    end

    # 2. Construct Open Knot Vector with (p + 1) repeated boundary knots
    tau_min, tau_max = tau_vec[1], tau_vec[end]
    num_internal = num_splines - p + 1
    internal_knots = collect(range(tau_min, tau_max, length = num_internal))

    knots = vcat(fill(tau_min, p + 1), internal_knots[2:end-1], fill(tau_max, p + 1))

    # 3. Efficient Iterative B-Spline Matrix Evaluation
    Phi, DPhi = eval_bspline_matrices(tau_vec, knots, p)

    # Partition of Unity Check across the interior domain
    if check_partition
        partition_sum = sum(Phi, dims=2)
        @assert all(abs.(partition_sum .- 1.0) .< 1e-8) "B-spline partition of unity check failed."
    end

    # 4. Trim Boundary Basis Functions (Option A: Exact φ = φ_τ = 0 at boundaries)
    # Trimming the first and last (p - 1) splines eliminates non-zero boundary terms
    trim_idx = p
    active_mask = (trim_idx + 1):(size(Phi, 2) - trim_idx)

    Phi_active  = Phi[:, active_mask]   # Size: N × M_active
    DPhi_active = DPhi[:, active_mask]  # Size: N × M_active

    # 5. Expanded Physics-Driven Candidate Feature Library Θ(X)
    e  = @view X_data[:, 1]
    q  = @view X_data[:, 2]
    tm = @view X_data[:, 3]
    S  = @view X_data[:, 4]
    Tz = @view X_data[:, 5]

    Theta = hcat(
        ones(N), e, q, tm, S, Tz,
        e.^2, e .* S, q .* Tz, e.^3, e.^1.5,
        e .* q, S .* Tz, q .* S, e .* Tz
    )
    num_features = size(Theta, 2)

    # 6. BLAS-Accelerated Numerical Quadrature
    # Trapezoidal Integration Weight Vector w
    w = zeros(N)
    w[1] = 0.5 * (tau_vec[2] - tau_vec[1])
    w[end] = 0.5 * (tau_vec[end] - tau_vec[end - 1])
    @inbounds for i in 2:(N - 1)
        w[i] = 0.5 * (tau_vec[i + 1] - tau_vec[i - 1])
    end

    # Integrate against Ψ(t) scaled library: G = Φ_active' * diag(w .* Ψ) * Θ
    Theta_scaled = (w .* Psi_vec) .* Theta
    G_matrix = Phi_active' * Theta_scaled        # Size: M_active × num_features

    # Integrate weak target derivatives: B = -DΦ_active' * diag(w) * X
    X_scaled = w .* X_data
    b_vector = -DPhi_active' * X_scaled          # Size: M_active × d

    return G_matrix, b_vector
end

## Analytical Justification and Change-of-Variables Derivation

### Change-of-Variables in the Weak Formulation

When transitioning from physical time $t$ to intrinsic desingularized time $\tau$, the weak inner product identity undergoes an exact transformation.

Given the intrinsic clock reparameterization:

$$d\tau = \frac{dt}{\Psi(t)} \implies dt = \Psi(t) \, d\tau$$

The physical weak formulation integral over a temporal domain $[t_0, t_f]$ for candidate term $\Theta(\mathbf{x})$ and test function $\phi$ is:

$$\mathcal{I}_t = \int_{t_0}^{t_f} \Theta(\mathbf{x}(t)) \, \phi(t) \, dt$$

Substituting $dt = \Psi(t(\tau)) \, d\tau$ yields the exact intrinsic-time weak integrand:

$$\mathcal{I}_\tau = \int_{\tau_0}^{\tau_f} \Theta(\mathbf{x}(\tau)) \, \phi(\tau) \, \Psi(t(\tau)) \, d\tau$$

This proves that the extra factor of $\Psi(t)$ inside `G_matrix = Phi_active' * ((w .* Psi_vec) .* Theta)` is mathematically required to preserve the original measure under dynamic time scaling.

### Theorem: Weak-Form Exactness Under Boundary-Trimmed B-Splines

**Theorem 1** *(Exact Weak Integration Identity)*. *Let $\{\phi_j(\tau)\}_{j=1}^{M_{\text{active}}}$ be the set of active cubic B-spline basis functions over the open knot vector $\mathbf{\tau}_{\text{knots}}$, constructed by trimming the $p$ boundary-overlapping splines on both ends of the domain $[\tau_0, \tau_f]$. Then for any continuously differentiable trajectory $\mathbf{x}(\tau) \in C^1([\tau_0, \tau_f], \mathbb{R}^d)$, the weak integration identity:*

$$\int_{\tau_0}^{\tau_f} \frac{d\mathbf{x}}{d\tau} \, \phi_j(\tau) \, d\tau = -\int_{\tau_0}^{\tau_f} \mathbf{x}(\tau) \, \frac{d\phi_j}{d\tau} \, d\tau$$

*holds identically with zero boundary error.*

*Proof.* Applying integration by parts to the left-hand side yields:

$$\int_{\tau_0}^{\tau_f} \frac{d\mathbf{x}}{d\tau} \, \phi_j(\tau) \, d\tau = \Big[ \mathbf{x}(\tau) \, \phi_j(\tau) \Big]_{\tau_0}^{\tau_f} - \int_{\tau_0}^{\tau_f} \mathbf{x}(\tau) \, \frac{d\phi_j}{d\tau} \, d\tau$$

By trimming the $p$ boundary-overlapping basis functions on both ends, every active spline $\phi_j(\tau)$ for $j \in \{1, \dots, M_{\text{active}}\}$ has its compact support $\text{supp}(\phi_j) = [\tau_{j}, \tau_{j+p+1}]$ contained strictly inside the interior open interval $(\tau_0, \tau_f)$. Consequently:

$$\phi_j(\tau_0) = \phi_j(\tau_f) = 0 \quad \text{and} \quad \left. \frac{d\phi_j}{d\tau} \right\vert{}_{\tau_0} = \left. \frac{d\phi_j}{d\tau} \right\vert{}_{\tau_f} = 0$$

The boundary term $\big[ \mathbf{x}(\tau) \phi_j(\tau) \big]_{\tau_0}^{\tau_f}$ vanishes identically regardless of the trajectory endpoints $\mathbf{x}(\tau_0)$ and $\mathbf{x}(\tau_f)$. $\blacksquare$
